# Chess-playing-robot

Робот-манипулятор для игры в шахматы на реальной доске. Камера определяет ход человека, шахматный движок Stockfish рассчитывает ответ, рука с электромагнитом переставляет фигуры.

## Что умеет сейчас

- Выпрямлять снимок доски, сделанный под углом, по четырём углам, отмеченным при калибровке
- Делить доску на 64 подписанные клетки a1–h8
- Описывать наблюдение доски в едином формате, общем для модулей зрения и шахматной логики

## Установка

```bash
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Запуск

Все команды выполняются из корня проекта.

Калибровка доски (один раз при установке камеры): открыть фото и кликнуть углы игрового поля в порядке a1 → h1 → h8 → a8, затем нажать `s`.

```bash
.venv\Scripts\python.exe -m src.vision.calibrate путь\к\фото.jpg
```

Тесты:

```bash
.venv\Scripts\python.exe -m pytest
```
